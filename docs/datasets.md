# Datasets

The thesis uses the **Screen2AX-Tree** dataset as its primary source, the **Screen2AX-Task** benchmark for downstream evaluation, and a **silver corpus** distilled from a frontier VLM teacher. None of the data is committed to this repository — fetch / regenerate as below.

## Screen2AX-Tree (primary)

Source: [`macpaw-research/Screen2AX-Tree`](https://huggingface.co/datasets/macpaw-research/Screen2AX-Tree) on HuggingFace. 1127 macOS screenshots from 112 applications, each paired with a hierarchical accessibility tree extracted from the macOS Accessibility API.

Linearize into the format consumed by the eval and training pipelines:

```bash
python src/screen2ax_eval/linearize_screen2ax.py export \
  --output-dir ./data/screen2ax_linearized
```

Produces:

```
data/screen2ax_linearized/
├── images/         # screenshots
└── annotations/    # one .txt per image — AX tree in the linearized format
```

The linearized format (one node per line, two-space indentation for hierarchy) is described in the thesis methodology chapter and in `README.md`.

## Screen2AX-Task (downstream benchmark)

Source: [`macpaw-research/Screen2AX-Task`](https://huggingface.co/datasets/macpaw-research/Screen2AX-Task). 5933 (screenshot, command, target-bbox) triples used for the grounding evaluation in the experiments chapter. The downstream protocol pairs each system's predicted AX tree with a fixed GPT-5 selector and counts a sample as successful when the selected node's box has IoU ≥ 0.5 with the target.

## Silver corpus (derived)

Generated by the Qwen3-VL-235B-A22B-Instruct teacher served via vLLM on the Screen2AX-Tree training and validation splits. Used as supervision for both the LoRA fine-tuning experiments and the YOLOv11l detector retraining.

```bash
./scripts/serve_vllm.sh &              # serve the 235B teacher in another terminal
python src/screen2ax_eval/inference.py \
  --input ./data/screen2ax_linearized \
  --output ./data/silver
```

## YOLO-formatted Screen2AX (derived)

For the silver-trained YOLOv11l detectors used in the hybrid pipeline:

```bash
python src/silver_to_yolo/convert.py \
  --input ./data/silver \
  --output ./data/yolo
python src/silver_to_yolo/validate.py --input ./data/yolo
```

## Qwen SFT JSON (derived)

For LoRA fine-tuning via `Qwen-VL-Finetune`:

```bash
python src/silver_to_yolo/build_qwen_sft_json.py \
  --input ./data/silver \
  --output ./data/qwen_sft/train.json
```

## Format notes

- Surrogate characters (`\ud800`) appear in some AX values from the Screen2AX-Tree HuggingFace dataset — sanitize with `.encode("utf-8", errors="ignore").decode("utf-8")` before writing.
- HF dataset images are 2× Retina; AX positions are 1× logical points. The `linearize_screen2ax.py` `--scale-factor` flag handles this.
- Multi-line `value="..."` attributes (e.g. text-editor content with newlines) must be escaped or truncated before serialization.
